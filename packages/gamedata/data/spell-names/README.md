# Spell names

`4b264ea90552ef077c0b5a159b64ed03738926ec`: the id, name and rank of every spell in the engine's spell table (`sim/core/spelldata/spells_auto_gen.go`) that
`assets/database/db.json`'s `spellIcons` (the same table db.bin carries) does not already name. Do not edit by hand; rerun the
script (engine-sync does, see `tools/engine-build/README.md`):

```sh
node packages/gamedata/scripts/extract-spell-names.ts --upstream <forever checkout>
```

The app loads it lazily (`loadSpellNames` in `src/spell-names.ts`) to name abilities and auras the engine reports
by spell id. 7433 of the table's 8562 spells are here.
